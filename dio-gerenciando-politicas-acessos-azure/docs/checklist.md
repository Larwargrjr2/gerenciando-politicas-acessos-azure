# Checklist do Laboratório

## Preparação

- [ ] Azure CLI instalado.
- [ ] Login realizado.
- [ ] Assinatura correta selecionada.
- [ ] Permissões verificadas.

## Policy

- [ ] Policy Definition identificada.
- [ ] Assignment criada.
- [ ] Escopo revisado.
- [ ] Efeito da política compreendido.
- [ ] Compliance consultado.

## Acesso

- [ ] RBAC revisado.
- [ ] Menor privilégio considerado.
- [ ] Escopos avaliados.

## Evidências

- [ ] Screenshot do Policy Assignment.
- [ ] Screenshot do Compliance.
- [ ] Screenshot do recurso avaliado.
- [ ] Saída dos scripts.
- [ ] Nenhum segredo publicado.

## Limpeza

- [ ] Recursos temporários removidos.
- [ ] Assignment de laboratório removida quando necessário.
- [ ] Resource Group removido.
